# Code for Modelling Diminishing Returns in Component Network Meta-Analysis
This repository contains the R and WinBUGs code to accompany the paper "Modelling Diminishing Returns in Component Network Meta-Analysis: Development, Evaluation, and Application" by Smith et al.

The folder Simulate_data contains files to generate the simulated datasets.

The folder Running_simulations contains the R script needed for running the simulations and the WinBUGS model txt files.

The folder R_files_to_run_models contains R code for running each model. 

The folder Results contains R files for analysing the results of the simulation study and producing plots.

The folder Application_to_LOS contains the files to apply the models to the length of stay dataset, the results of the application and code to produce the forest plot. The applied example uses data previously published by Freeman et al. (2018) and available online (https://doi.org/10.5281/zenodo.8006703); processed data and scripts required to reproduce the analyses presented in this article are provided in the repository.
